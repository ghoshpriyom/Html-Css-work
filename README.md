# YouTube Clone

A responsive YouTube-inspired website created using **HTML and CSS**.  
This project focuses on recreating the visual layout and design of YouTube without using JavaScript.

## 🚀 Features

- YouTube-style navigation bar
- Search bar UI
- Sidebar navigation
- Video thumbnail grid
- Video cards with titles, channel names, views, and upload information
- Responsive layout
- Clean and structured HTML/CSS

## 🛠️ Technologies Used

- HTML5
- CSS3
